How to Generate PNG Icons

  1. Right-click on the icon above and select "Save image as..."
  2. Save it as "icon.svg" in your project's icons folder
  3. Use an online SVG to PNG converter or image editing software
  4. Generate the following sizes: 16x16, 48x48, and 128x128 pixels
  5. Save them as icon16.png, icon48.png, and icon128.png respectively

Manual Icon Creation

If you prefer to create your own icons, you can use any image editing software to create simple icons with the following specifications:

  • icon16.png: 16x16 pixels
  • icon48.png: 48x48 pixels
  • icon128.png: 128x128 pixels

Recommended colors: #2c5aa0 (primary blue) and #1e3f7a (darker blue)
